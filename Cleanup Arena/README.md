# Cleanup Arena

A gamified email-cleanup application that turns the chore of managing your inbox into a fun, rewarding experience.

## Main Objective

Help users achieve and maintain inbox zero by turning email cleanup into an engaging game with points, streaks, and progress tracking.

## Planned Technology Stack

| Layer          | Technology                        |
| -------------- | --------------------------------- |
| Frontend       | HTML, CSS, vanilla JavaScript     |
| Backend        | Python, Flask                     |
| Database       | Supabase (PostgreSQL)             |
| Deployment     | Google Cloud Run                  |
| Version Control| Git & GitHub                      |
